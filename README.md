# Rickroll
Intended to Rickroll coding professors by opening the music video in Windows Media Player upon accepting some input in the terminal. The video is not provided here because I don't know how copyright works, but it can be found at https://archive.org/details/Rick_Astley_Never_Gonna_Give_You_Up. 
Only works on Windows with Windows Media Player installed. Run the program from the folder containing the video file. It will ask for integer input, then spit out a short block of text, wait 2.5 seconds, and start the video.
